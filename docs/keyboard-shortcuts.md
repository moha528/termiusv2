# Raccourcis clavier

Tous les raccourcis sont **personnalisables** : Réglages → **Raccourcis**.
Clique sur un raccourci pour l'enregistrer à nouveau ; les conflits sont
signalés. Valeurs par défaut :

## Navigation

| Action | Raccourci |
| --- | --- |
| Palette de commandes | `Ctrl+K` |
| Ouvrir les réglages | `Ctrl+,` |

## Productivité

| Action | Raccourci |
| --- | --- |
| Panneau Snippets | `Ctrl+Shift+S` |
| Historique des commandes | `Ctrl+R` |

## Onglets

| Action | Raccourci |
| --- | --- |
| Nouvel onglet | `Ctrl+T` |
| Fermer l'onglet | `Ctrl+W` |
| Onglet suivant | `Ctrl+Tab` |
| Onglet précédent | `Ctrl+Shift+Tab` |
| Rouvrir le dernier onglet fermé | `Ctrl+Shift+T` |

## Terminal

| Action | Raccourci |
| --- | --- |
| Rechercher dans le buffer | `Ctrl+Shift+F` |

> Sur macOS, `Cmd` déclenche les mêmes actions que `Ctrl`.

## Autres gestes

- **Double-clic** sur un onglet → renommer
- **Ctrl/Cmd + clic** sur une URL dans le terminal → ouvre le navigateur
- **Glisser-déposer** un host sur un groupe dans la sidebar → le déplace
